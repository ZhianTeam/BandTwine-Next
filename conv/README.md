## What the hell is this tool?
The NeG migration tool is a handy utility designed to give returning developers from legacy BandTwine a virtually seamless upgrade path.

## What can it do?
It fully automates the migration of your project's story and metadata files to BandTwine Next, requiring ***virtually no*** manual intervention.

## How do I use it?
It boils down to three simple steps:
1. `git clone` the source repository;
2. Copy your legacy project's `bandtwine_src` folder into the root directory of the new project;
3. Run `./conv/neg.js`, and leave the rest to time and Jesus.

Check out the [Quick Start Guide](/conv/QUICKSTART.md) or run `./conv/neg.js --help` for more usage options.
